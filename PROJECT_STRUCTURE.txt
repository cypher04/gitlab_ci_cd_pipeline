APPLY ORDER
===========

    backend/  ->  gitlab/  ->  env/dev/
    (human)       (human)      (pipeline)

Each stack depends on the one before it. A change under gitlab/ does not take
effect until a human runs `terraform -chdir=gitlab apply` - committing and
pushing it is not enough, because CI never applies that stack.


STATE
=====

    backend/    local file       backend/terraform.tfstate  (back this up)
    gitlab/     azurerm backend  gitlab-terraform.tfstate
    env/dev/    azurerm backend  terraform.tfstate
    env/stage   not configured
    env/prod    not configured

All remote state lives in the tfstate container of the storage account created
by the backend/ stack.
